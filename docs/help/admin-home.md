# Admin home and Simple mode

Admin home is the first page of the Admin area. It shows:

- **Getting started**, a short list of what's left to set up (add people, connect a phone line, and so on). A system admin also sees **Set up email**, ticked once a test email has arrived ([Email](email)). **Hide this list** once you're done.
- **Needs attention**: alerts that need you. *Nothing needs you right now* when all is well.
- **On a call now**, **Phone lines** and **System** at a glance.

![Admin home](screen:admin-home)

## Simple mode

The switch at the bottom of the Admin menu. With **Simple mode** on (the default), the menu shows only everyday pages. Turn it off to see the expert pages too: **Connections** (private connections to phone companies), **Webhooks** and **API keys** ([Webhooks and API keys](webhooks-and-api-keys)).

## Who sees the Admin area

- **Admin** and **System admin**: everything. Only a system admin sees Server settings.
- **Read-only admin**: sees every admin page, changes nothing.

## Confirm it's you

Changes that could let someone in or cost money (a new admin, a phone line, calls abroad) ask you to **Confirm it's you** first, with your passkey or your password and second step.
