# Incoming calls

When someone calls one of your numbers, it rings the extension you chose. **Incoming calls** shows each of **Your numbers** and where it rings, in one place.

![Incoming calls](screen:incoming)

## Changing where a number rings

Choose another extension next to the number. It's saved at once.

## Calls for any other number

A phone line can get calls for numbers you haven't listed (a landline often sends no number at all). **Calls for any other number** sets which extension rings for each line.

Adding and removing numbers is on each line's page ([Phone lines](phone-lines)).

To check where a call would go without making one, use the [call simulator](calling-permissions#the-call-simulator).

[Ring groups](ring-groups) ring several people at once; sending a phone number to one, office hours and voicemail come in a later update.
