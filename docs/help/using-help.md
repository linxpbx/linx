# Using Help

**Help** in the sidebar has the guides for your Linx. You see the ones for what you can do: admins see the admin guides too.

![Help](screen:help)

## Ask a question

Type a question in the search box, in your own words, like *how do I add a desk phone?* or *why can't my phone register?*. The best matching parts of the guides appear as you type; choose one to open it.

If nothing matches, try other words, or pick a guide from the list.

## Help for the page you're on

The question-mark button at the top right of every page, **Help for this page**, opens the guide about that page.

## Before you sign in

Under the sign-in box, **Help signing in** opens the guides about signing in, passkeys, a lost authenticator and being locked out, without signing in. See [Signing in](signing-in).

## Always up to date

The guides come with each Linx update, so they always match the version your server runs. See [What's new](whats-new).
